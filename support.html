Help & feedback

Support

Public assistance and feedback for this independent prototype are handled through the project's GitHub issue tracker.

Open a support issue ↗

Protect your privacy.

GitHub issues are public. Never include exported conversations, API tokens, login credentials, private conversation IDs, personal details or the SQLite database in an issue. For a sensitive report, request a private reporting channel without disclosing the sensitive content.

Before reporting a problem

  1. Verify the MCP service is running on the authorized server.
  2. Check whether imported conversations or saved memories are present.
  3. If using opt-in browser capture, confirm the extension is enabled and view its local retry status.
  4. Provide the application version, the non-sensitive steps to reproduce, and expected versus actual behavior.

Service availability

The product is a private alpha, not a publicly operated support service. There is no guaranteed response time or service-level agreement. For privacy questions, use the issue tracker without posting sensitive information.
