Privacy notice

This notice describes the currently implemented private alpha, not an undisclosed cloud service. The publisher is Bar Kwina, maintaining this project through the GitHub account RAZENWQ. Contact is via the project issue tracker; do not post personal data publicly.

1. Scope and data processed

The owner-operated memory application can store notes, decisions, project labels, message text, conversation identifiers, and timestamps. The owner may import a ChatGPT data export or enable browser capture for messages displayed in supported ChatGPT tabs. It does not have automatic access to the full account history via an OpenAI account API. Some images, attachments, and other non-text content are not indexed.

2. Purposes and user choices

Records are indexed only to provide search, retrieval and project continuity. The archive is populated by explicit save actions, user-provided imports, or optional browser capture that the owner enables. Browser capture can be disabled in the extension settings.

3. Storage and security

In the current alpha, archive data is saved to an owner-controlled Ubuntu server in SQLite, with file-access permissions. The application does not currently provide encryption at rest, a hosted multi-tenant account system, or publicly exposed authentication. The local MCP endpoint is not intended for direct Internet exposure. Do not store credentials, financial account details or information that you are not authorized to handle.

4. Sharing and external services

No advertising trackers or analytics scripts are embedded in this website. GitHub Pages hosts this public informational website and may process access information under GitHub's own policies. If the owner connects the archive to an AI assistant, text returned by a tool may be shared with the assistant provider as part of processing the requested answer; evaluate the provider's terms before connecting.

5. Retention, deletion and copies

Stored records generally remain in the local archive until the owner deletes them. The prototype provides tools to remove individual records and imported conversation messages. Deleting a ChatGPT conversation does not automatically remove a previously imported separate copy. Original export ZIP files and backups, if retained by the owner, must be managed separately.

6. Access and questions

The local operator controls the stored records and is responsible for access and deletion. For project privacy questions, open a GitHub issue without publishing personal or sensitive data. The implementation and this notice must be reviewed again before offering a hosted service to external users.
