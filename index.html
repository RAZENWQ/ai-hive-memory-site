Owner-controlled knowledge

Find your project history when you need it.

AI-HIVE Memory is an experimental MCP-based memory archive that helps retrieve project notes, decisions, and conversation text that you explicitly save or import.

Support & setup information →

Search saved knowledge

Search notes, decisions, and imported message text across projects.

Import with consent

Index text from user-supplied ChatGPT export files rather than accessing account history directly.

Optional browser capture

An opt-in companion extension can record visible conversations in supported browsers.

Current availability: private development alpha.

This site is product information, not a registration page or cloud service. The owner-hosted MCP server has not been approved by OpenAI and is not open to the public. The integration cannot automatically read conversations that have not been saved, imported, or captured with permission.

Control stays with the operator

The database runs on an owner-controlled server. You decide whether to import a historical export or enable browser capture. The current prototype uses local operating-system permissions for stored files; no multi-user hosted service is offered.

Before using this software, read the privacy notice and terms of use.
